# Daybook — Simple expense tracker

A calm, responsive personal finance dashboard built with React. Track income and expenses, keep an eye on your balance, and get a simple monthly spending overview.

## Run locally

```sh
npm install
npm run dev
```

## Features

- Add, edit, and delete income and expense transactions.
- Categorize expenses and set dates and amounts.
- Search and filter activity, or switch between this month and all time.
- View current balance, monthly income, and spending summaries.
- Persist transactions in browser local storage.
- Responsive layout for desktop, tablet, and mobile.

Run `npm test` for the test suite and `npm run build` to create a production build.
